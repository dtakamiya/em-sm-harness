## 入力と出力
| 項目 | 数え方（`history` の今日付けの操作と現在の状態から。EM の手入力なし） |
|---|---|
| 今日の完了 | `history` に今日付けの `done` がある（件数のみ） |
| 持ち越し | 状態が open/doing・`due` が今日以前・今日先送りしていない。日数は `due` との差のみ。理由は推測しない |
| 今日先送りした | 今日付けの `defer` がある |
| 新たな返信待ち | 状態が waiting かつ今日付けの `wait` / `delegate` がある |
| 明日の計画の種 | `due` が明日の open/doing、`next_check` が明日の waiting |
| 判断依頼 | `defer` が 2 回以上（次が 3 回目）。選択肢は drop / 分割。朝と同じ基準（[17](17-task-priority-and-waiting.md)） |

- `snooze_until` が未来のものは除外（朝と同じ）。各節は最大 5 件、超過は件数のみ
- 結論: 🔴 持ち越しあり / 🟡 先送り・新しい返信待ち・判断依頼あり / 🟢 それ以外
- 出力は標準出力の Markdown 1 枚。サンプルで 900 字未満（テストで確認）
