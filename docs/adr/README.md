# 設計判断の記録（ADR）

設計判断が重い項目は、設計レビュー会（em-builder と em-sm-analyst が別々に案を出し、互いに批評し、em-lead が集約、Ryoko が GO/NO-GO 判定）で決め、結論と理由をここに1件1ファイルで残す。

- ファイル名: `NNNN-短いタイトル.md`（連番）
- 雛形: [0000-template.md](0000-template.md)
- 状態: `提案` → `採用` / `却下` / `置き換え済み`
- 実データ・会社固有情報は書かない（架空例のみ）

対象の目安: 委任ポリシー、接続方式、データスキーマ、先回り検知の仕様など、後から変えにくい判断。軽い項目は ADR 不要。
