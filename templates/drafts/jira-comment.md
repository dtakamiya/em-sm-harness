# 下書きテンプレ: Jira コメント案

分類: 下書き（L1）。**Jira への投稿は EM**（秘書は書き込まない）。入力: Jira キャッシュ（[06](../../docs/design/06-cache-schema.md)）のチケット + 先回り検知（[18](../../docs/design/18-proactive-detection.md)）の「放置チケット」「ブロッカー」。

## 必須項目
- 冒頭に `【下書き・未送信】`
- コメントの型（状況確認 / ブロッカー確認 / 仕様確認 / 完了確認）を 1 つ選んで先頭に明示
- 対象チケットのキー（架空表記可）と、根拠にした事実（最終更新日・ステータス滞留日数など）
- コメント本文 **最大 2 案**（案A 短く / 案B 丁寧に）。担当者への問いは **1 コメント 1 問**
- `⟦EM が決める⟧` 欄: 期限・担当変更・優先度変更・スコープ判断など新規コミットになる箇所（本文には入れない）

## テンプレ
```
【下書き・未送信】コメントの型: {状況確認|ブロッカー確認|仕様確認|完了確認}
対象: {チケットキー}（担当: {匿名ハンドル}）
観察: {最終更新日 / ステータス滞留日数 / リンクされた課題の状態}

■ 案A（短く）
{問い 1 文}

■ 案B（丁寧に）
{宛名}さん、{一言}。{問い 1 文}。{判断に使う補足 1 文}

⟦EM が決める⟧
- {期限/担当変更/優先度のうち本文に入れなかった項目と、おすすめ 1 つ}
```

## EM が直す手間を減らす工夫
- 「遅れている」「止まっている」と断定せず、観察（滞留 N 日・最終更新日）だけを書き、理由は問いで聞く
- 約束・催促になる語（「〜までにお願いします」）は本文に入れず ⟦EM が決める⟧ に寄せる。EM は欄を埋めて差し込むだけ
- 人への評価に読める言い回しを避け、チケットの状態を主語にする（「担当の遅れ」ではなく「チケットの更新が止まっている」）
- 同じチケットに直近のコメントがある場合は、重複を避けて型を「完了確認」か見送りの提案に切り替える
- Jira のコメントは担当以外にも見える前提で、1on1 で扱う性質の話題は含めない

## 匿名化サンプル（架空）
```
【下書き・未送信】コメントの型: ブロッカー確認
対象: PROJ-12（担当: member-b）
観察: 最終更新 2026-09-28、「レビュー待ち」で 6 日滞留。リンク先 PROJ-9 は未着手

■ 案A（短く）
PROJ-9 の完了が前提になっていますが、着手の見込みは分かりますか。

■ 案B（丁寧に）
member-b さん、お疲れさまです。PROJ-12 は「レビュー待ち」で 6 日経っています。リンクしている PROJ-9 が前提でしょうか。差し支えなければ状況を教えてください。

⟦EM が決める⟧
- PROJ-9 の優先度を上げるか、期限を置くか（おすすめ: 回答を見てから判断）
```
