# 下書きテンプレ: 議事録下書き

分類: 下書き（L1）。**Confluence への掲載・参加者への共有は EM**（秘書は書き込まない）。入力: EM が貼った会議メモ / 文字起こし（ローカルのみ）。

## 必須項目
- 冒頭に `【下書き・未送信】`
- 会議名・日付・参加者（匿名ハンドル可）・目的を 1 行ずつ
- **決定事項**（決まったことだけ）/ **未決事項**（結論が出ていない論点）/ **アクション**（担当・期限はメモにあれば）を分けて書く
- 決定事項の判定基準: 合意・決定の発言がメモに明示されたもののみ。提案段階・「〜かも」は未決事項
- メモに明示されていないものは「決定」「アクション」にしない。曖昧なものは `要確認` と付けて未決事項へ
- `⟦EM が決める⟧` 欄: 担当の割り当て・期限の設定・共有範囲など新規コミットになる箇所（本文には入れない）

## テンプレ
```
【下書き・未送信】議事録: {会議名}（{日付}）
参加者: {匿名ハンドル}  目的: {1 行}

■ 決定事項
- {メモに「決まった」と読める発言がある事項}

■ 未決事項
- {論点}（要確認: {誰に何を聞けば決まるか}）

■ アクション
- {内容}（担当: {メモで名指しされた人のみ}、期限: {メモにある場合のみ}）

⟦EM が決める⟧
- {担当・期限が空欄のアクションの割り当て案と、おすすめ 1 つ}
- {共有範囲（参加者のみ / チーム全体）}
- 除外した話題の有無と別扱い案（内容は書かない）: {有 / 無、有なら別扱い案}
```

## EM が直す手間を減らす工夫
- 担当・期限が発言から読み取れないアクションは空欄にして ⟦EM が決める⟧ へ送る。秘書が補完して約束を作らない
- 発言者の意図や評価を推測せず、発言された内容だけを書く（人への解釈は書かない）
- 決定と未決の境界が怪しい項目は未決側に倒し、「要確認」で聞く相手を示す
- 1on1 や評価に触れる話題が混じっていたら議事録から除き、EM に別扱いを提案する
- 全体で 60 秒で読める量に収める。詳細な経緯は付けない

## 匿名化サンプル（架空）
```
【下書き・未送信】議事録: 週次定例（2026-09-30）
参加者: member-a, member-b  目的: リリース前の残課題確認

■ 決定事項
- リリース判定は金曜の定例で行う

■ 未決事項
- 負荷試験を実施するか（要確認: member-b に環境の空き状況）

■ アクション
- テスト結果の集計（担当: member-a、期限: 未記載）

⟦EM が決める⟧
- 集計の担当: 未定 → 割り当て（おすすめ: member-a）
- 集計の期限（おすすめ: 木曜）
- 共有範囲（おすすめ: 参加者のみ）
- 除外した話題: 無
```
