# 下書きテンプレ: Slack 返信案

分類: 下書き（L1）。**送信は EM**。入力: 貼り付け構造化（[13](../../docs/design/13-slack-paste-input.md)）の `request` / `question` / `decision` 種別。

## 必須項目
- 冒頭に `【下書き・未送信】`
- 返信の型（回答 / 受領のみ / 確認質問 / 期限の相談）を 1 つ選んで先頭に明示
- 返信本文 1 案目（短い）と 2 案目（丁寧）。**最大 2 案**
- `⟦EM が決める⟧` 欄: 期限・約束・割り当てなど新規コミットになる箇所（本文には入れない）
- 元発言の出典（貼り付け日・メッセージ ID）。本文の長い引用はしない

## テンプレ
```
【下書き・未送信】返信の型: {回答|受領のみ|確認質問|期限の相談}
出典: {貼り付け日}:{メッセージID}（相手: {匿名ハンドル}）

■ 案A（短く）
{結論 1 文}。{必要なら理由 1 文}。

■ 案B（丁寧に）
{宛名}さん、{お礼 or 受領の一言}。{結論}。{理由・補足}。{次の一手（秘書が決められる範囲のみ）}

⟦EM が決める⟧
- {期限/約束/担当のうち本文に入れられなかった項目と、おすすめ 1 つ}
```

## EM が直す手間を減らす工夫
- 案 A/B はトーン違いのみ。内容は同じにして、選ぶだけにする
- 約束になる語（「〜までにやります」「担当します」）は本文に入れず ⟦EM が決める⟧ に寄せる。EM は欄を埋めて差し込むだけ
- 敬語の強さは `config/local.*` の口調設定に従い、EM が直した箇所は feedback-inbox 経由で次回に反映
- 相手の意図を断定しない。確信がなければ「確認質問」型にする

## 匿名化サンプル（架空）
```
【下書き・未送信】返信の型: 確認質問
出典: 2026-10-05:s-01（相手: member-a）

■ 案A（短く）
デモ環境の件、見ました。対象の日付は 10/9 で合っていますか。

■ 案B（丁寧に）
member-a さん、ご連絡ありがとうございます。デモ環境の準備について、対象は 10/9 のデモでよいか確認させてください。範囲が分かれば担当の調整に入れます。

⟦EM が決める⟧
- 担当の指名と期限（おすすめ: 日付確認の返信後に決める）
```
