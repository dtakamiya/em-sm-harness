# 下書きテンプレ: 1on1 アジェンダ案

分類: 下書き（L1）。入力: 前回の持ち越し（tasks）・本人の発言（会議メモ・貼り付け）のみ。**Jira 指標（jira_metrics・滞留日数・他チケットとの比較）は入力にしない**（[22](../../docs/design/22-jira-metrics-catalog.md) §1。個人の評価材料に化けるため）。**評価・報酬・懲戒・機微な共有は材料のみ。結論・推奨は書かない**（[14](../../docs/design/14-output-quality-checklist.md) D4）。

## 必須項目
- バナーの次の行（実質の 1 行目）に結論と EM がやること。バナーは「未送信」の目印で結論の行に数えない（[14](../../docs/design/14-output-quality-checklist.md) A1/A3）。例: 「準備済み。EM がやること: 解釈欄を読んで要否を決める（判断不要）」
- 冒頭 `【下書き・未送信】`（相手は匿名ハンドル。実名は現地で EM が差し替え）
- 前回の持ち越し（アクション・約束、出典日付付き）
- 観察（事実）: 出典付き。評価語・推測語を入れない
- 解釈の候補: **最大 2 つ**。「〜の可能性」。確認方法を 1 行添える
- 聞く問い（オープンクエスチョン 3 つまで）。相手が話す時間を優先する構成
- 観察は 3 点まで。出典はタスク ID（tasks）か発言日付のみ
- 個人別の時系列・ランキング・他メンバーや平均との比較は作らない（今回の事実のみ）

## テンプレ
```
【下書き・未送信】1on1 アジェンダ案（相手: {匿名ハンドル} / 予定: {日付}）
結論: 準備済み。EM がやること: {解釈欄の要否を決める / 判断不要}
目安: 30 分。話す比率は相手 7 : EM 3

1. 前回の持ち越し（5分）
   - {アクション} — 出典 {日付}（状態: {完了|継続|未確認}）
2. 観察（事実）
   - {事実}（出典: {チケットID or 日付}）
3. 解釈の候補（断定しない）
   ① {候補1}の可能性 → 確認: {何を聞くか}
   ② {候補2}の可能性 → 確認: {何を聞くか}
4. 聞く問い
   - {問い1}
   - {問い2}
5. 相手のターン（自由）
⟦EM だけが扱う⟧ 評価・報酬・機微な共有に触れる話題があれば、材料の有無のみ記載
```

## EM が直す手間を減らす工夫
- 観察は 3 点まで。多いと EM が削る手間が出るため、優先度の高い順に切る
- 問いは「はい/いいえ」で終わらない形で最初から書く
- 事実の欄と解釈の欄を見出しで分け、EM は解釈欄だけ消せば事実が残る
- 感情の兆候は「signal」の事実表現（発言の近い言い換え）にとどめ、気分の断定をしない

## 匿名化サンプル（架空）
```
【下書き・未送信】1on1 アジェンダ案（相手: member-b / 予定: 2026-10-09）
結論: 準備済み。EM がやること: 解釈欄の 2 案を読み、聞くか決める（判断不要の項目なし）
目安: 30 分。話す比率は相手 7 : EM 3

1. 前回の持ち越し（5分）
   - テスト環境の手順書を見直す — 出典 2026-09-25（状態: 未確認）
2. 観察（事実）
   - 持ち越しタスク EX-12 が未完了のまま 10/3 から続いている（出典: tasks の EX-12）
   - 10/6 のデイリーで「割り込みが続いている」という発言（貼り付け 10/6）
3. 解釈の候補（断定しない）
   ① 見積もりが小さかった可能性 → 確認: 当初の想定と差が出た箇所
   ② 割り込み対応が重なった可能性 → 確認: 対応した依頼の件数と頻度
   （2 つの観察は同時期に並んでいる＝共起。関係は未確認）
4. 聞く問い
   - 今スプリントで一番時間を取られたことは何ですか
   - 手放せそうな作業はありますか
5. 相手のターン（自由）
⟦EM だけが扱う⟧ 該当なし
```
