# em-sm-harness

EM（エンジニアリングマネージャー）とスクラムマスター業務を支援する Claude Code ハーネス。

- **入力**: Jira（API トークン接続・読み取り中心）／ Slack の内容を手動で貼り付けたテキスト
- **出力**: 日次ブリーフ・スプリント健全性チェック・リスク/障害物台帳・レトロ/1on1 準備・状況サマリ

## ステータス

設計フェーズ。**Jira への実接続は未実施**（接続方式を設計書で固めている段階）。
設計書は [docs/design/](docs/design/) を参照。

## 原則

- 実データ（Jira 取得結果・Slack 貼り付け・個人名を含む出力）は `data/` に置く。`data/` は gitignore 済みでコミットしない
- API トークン等の秘密値はコード・設計書・コミットに含めない（環境変数名のみ記載）
- 外部ツール前提は Jira + ローカル Markdown/JSON のみ
- 人に関する出力は「観察された事実」と「解釈の候補」を分ける

## ディレクトリ

```
docs/design/   設計書
data/          実データ置き場（gitignore）
```
